# 收藏卡质量检查表

按实际交付选择适用项目。纯插画不需要虚构模型或材质检查；声称有深度、镭射或交互的作品，需要对应的实际证据。未检查的项目写“未检查”，不填“通过”。

## 创作与身份

- [ ] 用一句话说明这张卡发生的事，而不只是列服装与装饰。
- [ ] 身份参考与姿态、风格、光线参考已分开标注。
- [ ] 角色的脸型、发型、标志饰品和轮廓保持一致。
- [ ] 一组卡的镜头、视线、情绪和剪影有可辨认的变化。
- [ ] 表情回应场景，眉眼、嘴角和姿态没有互相矛盾。
- [ ] 系列的地点、材料与光线语言连贯。
- [ ] 实际使用的 AI 工具、参考来源和人工修订范围已记录。
- [ ] 拟公开的素材具备适用权限，遵守仓库的许可与署名要求。

## 解剖与动作

- [ ] 头、颈、肩与躯干的连接能被清楚解释。
- [ ] 每条可见腿的骨盆至鞋尖连接可追踪，遮挡顺序合理。
- [ ] 骨盆、座面、承重脚与支撑手的接触成立。
- [ ] 轻触、承重与悬空动作分别判断，没有强塞支撑物。
- [ ] 手指抓住实际的道具；必要的动作接点没有完全藏起来。
- [ ] 结构修正之后，完整姿态仍然自然、舒展、好看。

## 边框与画面

- [ ] 边框与真实插画、最新卡背的主题及材料对应。
- [ ] 不同主题有自己的结构，不只是同一框型换色。
- [ ] 完整装饰线条连贯，没有靠细碎裁片拼出破损花纹。
- [ ] 在缩略图和正常卡片尺寸上，插画仍是视觉主体。
- [ ] 脸、手、发梢、角、翅尖、鞋和重要道具没有被装饰压住。
- [ ] 边框中央窗口的 Alpha 由解码像素检查，并叠到实图复查。
- [ ] 已有合适的手绘边框被保留，没有无意义地重复套框。

## 镭射与深度：按宣称能力检查

- [ ] 清楚标明绘画体积、整卡旋转、分层视差、微浮雕与几何浮雕的区别。
- [ ] 镭射变化能随观察角度辨认，关键肤色和画面细节保持可读。
- [ ] 正面与左右斜视分别查看，没有用强白光遮住材料问题。
- [ ] 图层共享尺寸与坐标，透明区域为真实 Alpha。
- [ ] 发丝、镂空、把手孔与物件边缘的前景归属正确。
- [ ] 背景补全在前景移动后不露出重影或硬接缝。
- [ ] 高度、法线与实际材质共同形成可读体积；非零 Z 不被当作充分证明。
- [ ] 细物件附近没有被深度插值拉成条带，裁切边界没有浮起的矩形薄片。
- [ ] 人物、前景、地面与道具的深度支持原来的接触关系。
- [ ] “原画”选项确实显示约定的原图；低动态偏好与原画选择分别生效。

## 卡册与交互

- [ ] 横卡和竖卡保留完整比例，没有大块黑边或不必要的裁切。
- [ ] 两张、少量或末页卡片作为一组居中，实际尺寸足够阅读。
- [ ] 可见的已获得卡片能够打开真实的完整查看界面。
- [ ] 未获得卡位不泄露名称、类别、图片地址或图片尺寸等线索。
- [ ] 常驻材料与转场相匹配，载体边缘没有挤占主要展示面积。
- [ ] 换组在覆盖期间提交，新内容准备好后再揭示。
- [ ] 转场使用真实布局坐标，混合横竖比例与窗口变化后仍对齐。
- [ ] 键盘、触摸、关闭、回正与低动态替代路径可用。
- [ ] 隐藏或离屏时停止无意义绘制，关闭后实际释放 GPU 与事件资源。

## 版本、工程与公开说明

- [ ] 作品身份、插画版本与工艺版本分开记录。
- [ ] 正反面和关键资源的尺寸、摘要、配置与渲染入口对应准确。
- [ ] 更换原图后重新检查受影响的蒙版、背景、深度、贴图和边框。
- [ ] 实际最终入口没有缺资源或 shader 编译错误；截图等待资源加载完成。
- [ ] 左右对照之前各自回正，记录的是实际姿态而不是按钮标签。
- [ ] 真实打包后的资源及模块能被消费者加载，没有手改生成目录来掩盖问题。
- [ ] 说明区分技术检查、画面审查、用户审美接受和产品安装状态。
- [ ] 只声明确实查看过的对象与范围，代表性抽检不写成全量验收。
- [ ] 展示页准确描述自身能力；普通图片倾斜不宣传为完整人物三维模型。

记录建议：为每个问题写下“现象 → 原因假设 → 最小修改 → 实际观察”，并保留修改前后的版本。检查完成后，不需要为了凑次数反复重跑；只对后续变化、新失败或未解风险继续验证。
