# 从插画到收藏卡：一套可复用的制作方法

漂亮的插画是起点。一张完整的收藏卡，还需要角色一致性、清楚的画面叙事、合适的边框、可信的材料表现，以及实际可用的展示交互。

这份教程整理自 Luma 卡牌的 AI 辅助创作与交互制作经验。它是一份方法指南，不是完整的自动生产工具。展示图片只证明所展示的画面；具体卡片是否具备几何浮雕、镭射或完整运行时，应以对应资源和实际渲染为准。

## 1. 先设计发生的事，再设计装饰

为每张卡写一句具体的场景描述：**谁在什么地方，正在做什么，注意到什么，又产生了怎样的反应。**

只更换服装或背景，容易得到一整套相同的正脸、歪头和微笑。先做一个小型设计表，再决定细节：

| 维度 | 可以变化的选择 |
| --- | --- |
| 观察位置 | 平视、侧面、背影、俯视、环境远景、手部近景 |
| 身体动作 | 回望、翻书、演奏、避雨、整理物件、安静等待 |
| 视线目标 | 书页、远处的光、手中物件、同行者、画面外的事件 |
| 情绪 | 专注、松弛、惊喜、迟疑、释然、开怀 |
| 构图节奏 | 对角线、留白、前景遮挡、建筑框景、横向展开 |

用头发、脸型、眼睛、标志配饰和轮廓保持身份，用镜头和行动创造新意。角色没有看向观众，也可以非常有辨识度。表情要让眉眼、嘴角、肩颈和手势共同参与。

系列需要共同的世界：先约定建筑、地理、植被、材质和光线，再在其中变化时间、天气与观察位置。共同色调只是系列感的一部分。

## 2. 给参考图分工

分别标明身份参考、姿态参考、光线参考和待编辑原图。身份参考不自动规定新图的头部角度、身体姿态或表情。

一个实用的创作简报可以写成：

> 保留既定角色的脸型、发色与标志饰品。她侧身坐在窗边整理一封被雨打湿的信，视线落在纸面，双肩放松。镜头略低于眼睛，窗外反射与室内暖光形成层次。先让手与信纸的动作清楚，再安排服装、背景细节和边框。

收到结果后，与参考并排比较。换了一只手、增加一个道具或堆满新背景，都可能仍然沿用了旧图的完整展示姿态。AI 输出需要人工挑选、修订与核对；记录实际使用的工具和修改范围，不把提示词当作质量证明。

## 3. 先看身体连接，再看漂亮细节

放大检查头颈与肩线：从脊柱、肩部、颈部追踪到头骨，确认转头、低头和倾斜都有合理的结构支持。

逐条追踪腿部的骨盆、股骨、膝盖、小腿、脚踝和鞋。交叉或遮挡处要能解释每条腿从哪里进入、从哪里出来，以及谁在前面。两个完整鞋尖不能证明两条腿连接正确。

把接触分成三种：承重、轻触、悬空。座面承托骨盆；手指握住实际的把手；演奏动作要有可见的持握和接触。悬起的脚不需要硬塞一块台阶。若局部补丁反复制造新问题，重新设计构图或环境，比继续增加支撑物更有效。

结构正确之后，再看动作是否舒展、重心是否自然、剪影是否好看。解剖通过与审美通过是两件事。

## 4. 边框从画面里长出来

先看完整画面和最新卡背，找出共同的材质与符号。蓝蔷薇可以使用细银藤与深蓝花瓣，秋日庭院可以使用铜、枫叶与灯光，月相主题可以使用轨道与刻度。不同主题不必拥有相同的四角花团。

如果系列要求统一框型，先定义轮廓、主纹样和材料，再为每张图调整开口、角部重量和颜色。如果作品要求逐张匹配场景，则让场景决定边框，保留系列卡背与身份信息即可。

精致来自完整的线条、叶片结构、雕刻节奏与材料层次。把大角花缩成小碎片、拼接重复细条，容易破坏连续的藤蔓和轨道。尽量在目标横竖比例上完成整幅边框设计。

把框叠在真实插画上，按最终显示尺寸检查：脸、手、发梢、角、翅尖、鞋和重要道具都需要空间。透明中央窗口并不能自动保护边缘处的这些细节。已有相容的手绘边框可以保留，避免再套一层通用金属框。

## 5. 说清楚“立体”是哪一种

| 能力 | 实际改变什么 | 不能据此宣称什么 |
| --- | --- | --- |
| 绘画体积 | 明暗、遮挡、接触阴影和材质笔触 | 已有三维模型 |
| 整卡倾斜或翻转 | 卡片整体的朝向 | 人物拥有独立深度 |
| 表面微浮雕 | 局部法线及定向光照 | 人物被重新雕刻 |
| 分层视差 | 前景、人物、背景的相对位移 | 完整的封闭人物模型 |
| 几何浮雕 | 网格高度、法线和遮挡关系 | 任意角度都成立的完整角色 |
| 卡体与边框几何 | 厚度、倒角、凸起装饰和侧边 | 卡片内部场景也有体积 |

先选择需要的能力，再制作资源。普通展示页的 CSS 倾斜很适合表达拿起卡片的感觉，但应明确标为整卡交互展示。真正的场景深度需要相应的分层、深度或网格数据。

## 6. 镭射是随视角变化的材料

用明确的材料区域控制光谱：金属雕纹、水面、玻璃、服装局部和边框都可以参与。脸、皮肤和需要安静阅读的焦点通常应该保留原有色彩。

让光谱相位或高光方向响应观察角度，时间动画只是可选补充。固定的彩虹贴图与扫过全图的白光，很容易遮住原画。先确认正面清楚，再比较左右斜视时是否出现可辨认的材料变化。

保留强度控制，并分别设计低动态效果与“原画”模式。减少动态可以停在一个稳定姿态；用户明确选择原画时，则不应再挂载额外的镭射、浮雕或边框处理。

## 7. 分层、透明度与深度一起制作

各层应共享画布尺寸、坐标和裁切规则。按效果需要准备完整背景、人物或物件、前景、边框，以及必要的深度与材料遮罩；没有需求的层不必为了凑结构而创建。

透明必须来自真实 Alpha。PNG 扩展名、棋盘格外观或图像模型的回答都不能证明透明有效。解码 RGBA 像素，检查背景残留、细发丝、羽毛、饰件和中央窗口，同时叠到浅色、深色背景上查看。

人物的发束间隙、冠冕镂空和把手内孔，应保留真实背景。分割模型可能把这些空隙填满，也可能漏掉细线与浅色轮廓。先修正前景属于谁，再讨论深度。

补全背景需要在倾斜后仍连贯。前景移开后，不应出现第二个人物、硬接缝或无法解释的反射。人物、栏杆、地面与座椅之间的相对深度也必须支持原来的接触关系。

细把手等轮廓即使 Alpha 正确，仍可能因轮廓外的深度突降而被网格插值拉成条带。分别检查透明归属与高度场；必要时在不可见边界外提供平滑的深度支撑，更新法线，再检查双向斜视。不断擦薄 Alpha 或盲目加面数，通常不能解决根因。

开放式 2.5D 表面从侧面看可能显得悬浮。对于薄卡浮雕，可以探索在接近侧视时平滑回到卡面；对于触及原图裁切边界的衣摆，可以探索空间上的边缘回落。这些都是有条件的表现策略，不能冒充闭合三维模型，也不能以裁掉原画来隐藏缺陷。

## 8. 让每次修改都有明确身份

将作品、插画版本和工艺版本分开。建议记录作品编号、版本号、正反面尺寸、原图摘要、分层与深度资源摘要、边框配置、实际渲染入口，以及各项检查的状态。

原图变动后，旧蒙版可能不再注册，旧背景补全、深度、镭射遮罩与模型贴图也可能失效。只有证明字节未变、位置仍吻合时，才复用相应资源和检查结果。不要只替换一个正面文件，却继续宣称旧运行时已经验收。

保留旧的已完成版本时，使用新身份登记替代版本。收藏记录、评价和历史说明各自绑定准确版本；产品是否把旧版作为隐藏彩蛋，是单独的玩法选择，不是通用制作标准。

## 9. 展示容器也需要设计

横卡使用横向空间，竖卡使用竖向空间；保留完整比例，避免裁切，也不要把横卡塞进黑色竖框。两张或末尾不满一组时，将整组水平和垂直居中。展示载体可以放四张，但数量应服从可读尺寸。

卡册可以是书，也可以是盛水的贝壳、花瓣托盘、晶体阵列或舞台。一起设计常驻状态与换页动作：水波覆盖、旧卡沉没、新卡浮起；花瓣散开，再聚成新卡；舞台火焰遮住旧卡，再揭示下一组。材料应主导动作，而不只是换一张装饰底图。

转场按“覆盖 → 替换 → 揭示”组织。只有旧卡被充分遮住才替换数据，并等待新组实际提交与图片可用后再揭示。使用真实卡片布局来确定粒子和遮罩位置；不同横竖比例下，统一网格中心可能已经不准确。

提供静态或低动态替代方案，卡片打开、关闭与切换都应能独立完成。如果产品存在未获得卡位，未揭晓的卡片不要因尺寸、图片地址或预览加载而提前泄露身份。展示图集与真实收藏库存应分离。

## 10. 在真正的消费入口验收

检查最终渲染出来的卡，不只检查素材目录或 ready 标志。每次先回正，再分别转向左、右，记录最终角度；增量指令可能使“左转后右转”只回到正面。

查看静态原画、材质正面、左右斜视、背面、横竖卡、窄屏与大小变化。重点寻找：人物重影、轮廓条带、背景露洞、框压住主体、镭射洗白、侧边脱离和图片裁切。

使用 Blender 与 WebGL 时，明确坐标轴、UV 和观察方向的转换；网格转换后的局部空间不一定等于卡片根空间。自定义 Blender 节点图通常需要在实时渲染器中重新实现，不能把一次模型导出当作材质效果的完整转移。

源代码编译、真实打包后的资源路径、浏览器 GPU 渲染与安装后的运行是不同层次。按交付范围检查相应层次；记录代表性抽检的具体对象，不把几张卡的通过扩展成全库逐张验收。

只激活当前需要的查看器。关闭时释放动画帧、监听器、纹理、网格和渲染器；页面隐藏或载体离屏时暂停持续绘制。保留无需 GPU 的失败回退，但不要用静态回退的成功掩盖本应存在的工艺加载失败。

继续使用 [质量检查表](quality-checklist.zh-CN.md) 把发现与修正记录下来。检查用于定位问题；最终的美感仍需要对完整画面作出判断。
