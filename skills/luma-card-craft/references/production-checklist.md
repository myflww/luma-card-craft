# 从好看的插画到可靠的收藏卡

本文件是新整理的通用指导，采用 CC BY-NC-SA 4.0。数量、玩法和交付介质由实际项目决定。

## 画图前

- 用一句话写清楚这一刻发生的事，再选表情、视线、动作与镜头。
- 身份参考固定发色、脸部特征、标志物与比例；姿势、情绪和环境参考分开指定。
- 一组卡比较镜头、头肩方向、手势、重心和表情，不以换衣服充当构图多样性。
- 系列共享具体世界：建筑、地理、植被和材料具有连续性，地点和天气可以变化。

## 原画审查

- 从胸廓追到肩、颈、头，再从骨盆追到左右脚；遮挡不能掩盖明显错误的肢体连接。
- 标出真正承重、轻触与自由悬空的部分。检查手握住的是物体本身，座椅是否支撑骨盆。
- 在整图与实际显示尺寸检查焦点，头发、衣料和装饰不能使动作难以理解。
- 需要局部修订时明确保护区；改眼神不等于重做笑容，改环境不等于移动人物。

## 精细边框

- 同时看卡背与插画，确定纹样、材料、主纹章及留白，不凭系列名称猜颜色。
- 以画面细节呼应装饰。秋日灯铜、潮池贝母、蓝蔷薇银枝或月相刻度可以有不同结构。
- 边框应完整连贯，勿把大花裁成四角碎片来达成数值上的“细”。
- 解码 RGBA 检查透明窗，也看真实卡图；数字达标不能证明花瓣没有被裁断。
- 若原画已有合适边框，保留它。反复叠加新框会造成双边、遮挡和材质冲突。

## 图层和表面

- 所有层共用同一画布、坐标和裁切规则；禁止用几张独立生成、位置不同的图假装已经配准。
- 主体蒙版保留头发、角、伞柄和细挂饰。头发、冠冕和把手中的真实空洞应透出背景。
- 干净背景应连续，不能留下人物残影；两侧倾斜都检查重复轮廓和填补接缝。
- 深度按可解释的身体、道具和景物来设计。面部亮点不是最前点，黑色衣服也不是深洞。
- Alpha 可以正确但几何仍撕裂。薄物体边缘外的深度支持应连续，避免可见三角形跨过骤降边界。
- RGB 法线、图层视差和位移网格分别记录；不要把其中一种写成另一种。

## 镭射和材质

- 使用视角、法线与受控图案驱动光谱相位。仅按时间滚动的彩虹不等于角度响应。
- 保留不同材料：银叶、铜边、宝石、绸面、水面与皮肤不应同样发光。
- 正面保留原作颜色；左右转动时有可观察但不过曝的变化。脸部和主要手势优先清晰。
- 静态、减少动态和 WebGL 不可用回退有各自明确状态，不把技术回退当作完整材质通过。

## 卡册与检查器

- 横卡按横卡长宽比显示，竖卡按竖卡显示；少量卡片居中，对不同尺寸留出实际空间。
- 点击可查看完整卡片；显示静态原画、背面、侧面、复位与清晰的退出方式。
- 特殊载体可以是潮池、花盘、晶片或舞台。载体表现服务卡片，装饰不能挤占大部分可用空间。
- 转场可分成旧卡退场、遮蔽、内容切换、新卡入场。水波先覆盖旧卡，旧卡沉下，再让新卡浮起。
- 转场期间管理输入和焦点，减少动态时直接或轻缓切换；不让动画速度损害阅读。

## 来源与验收

- 用稳定作品 ID + 独立版本 ID 管理替换，绑定正背面哈希、蒙版、深度、几何和材质来源。
- 新源图不能直接沿用旧验收；未变化的资源也要证明仍配准。
- 保留旧完成版及其用户记录。是否能抽取、是否隐藏、是否显示错版由产品合同决定。
- 看完整卡的正面、左右倾斜、背面、横卡、窄屏和缩放；检查资源失败、shader 错误和关闭后释放。
- 代表性实测只说明那些样本。分别列出源检查、GPU 观察、打包验证和实际安装证据。
- 原始证据、失败和局限保留在自己的项目里；公开教程使用通用结论，不泄露本机路径或用户数据。
